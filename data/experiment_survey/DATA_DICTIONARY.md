# Study 3 — Spring 2026 survey · Data dictionary

This is the dataset behind the paper's **between-subjects experiment**
(Control / Treatment A / B / C). Use it for any new analysis.

## Which file to use

| File | Use it for |
|------|-----------|
| **`study3_spring2026_survey.csv`** | **START HERE.** Analysis-ready: one row per participant×pitch rating, numeric 1–4 items, readable column names, a `Condition` label. This is the file the Section 2.5 hypothesis-testing script reads. |
| `mergedFinal.csv` | The original processed export (same rows) with the Likert values stored as **text** labels and cryptic `Grid*_*` column names. Equivalent content; prefer the file above. |
| `mergedFinal_demo.csv` | Same rows **+ participant demographics**. Use if your analysis needs demographics. |
| `raw_scores_by_condition/*.csv` | The same data pre-split into one file per condition (convenience). |

All of these are regenerated by `code/make_raw_scores.py` from `mergedFinal.csv`.

## Columns of `study3_spring2026_survey.csv`

| Column | Type | Description |
|--------|------|-------------|
| `Condition` | string | `Control`, `Treatment A`, `Treatment B`, or `Treatment C` |
| `Group` | string | internal code: `Group1`=Control, `Group2`=A, `Group3`=B, `Group4`=C |
| `ResponseId` | string | Qualtrics participant ID (a participant rates 2 pitches → 2 rows) |
| `PitchID` | int | Kiva borrower profile that was rated |
| `Q1 … Q15` (named) | int 1–4 | the 15 perception items, Likert-encoded (see below) |
| `Investment_pct` | float | investment allocation chosen: 25 / 50 / 75 / 100 |

### Likert encoding (all Q items)
`1 = Highly Ineffective · 2 = Somewhat Ineffective · 3 = Somewhat Effective · 4 = Highly Effective`

### The 15 perception items (3 sustainability dimensions × 5 criteria)

| | Credibility | Emotional Appeal | Logical Reasoning | Timing | Clarity |
|--|--|--|--|--|--|
| **Environmental** | Q1 | Q2 | Q3 | Q4 | Q5 |
| **Social**        | Q6 | Q7 | Q8 | Q9 | Q10 |
| **Economic**      | Q11 | Q12 | Q13 | Q14 | Q15 |

Column names spell this out, e.g. `Q7_EmotionalAppeal_Social`,
`Q13_LogicalReasoning_Economic`.

The **16 outcome variables** used in hypothesis testing = these 15 items +
`Investment_pct`.

## Analysis unit
A row = one participant's rating of one pitch. The paper's statistics (Table 2,
Table 3, Fig 2/3/5/6) are computed at the **row** level, giving
n = 178 (Control) / 230 (A) / 310 (B) / 370 (C) rows.
